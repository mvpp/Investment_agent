# Auditing calculator inputs

For a dated memo, set `ticker`, `period_start`, `period_end`, `unit`, `as_of` and `evidence` in each input. Both calculators accept `--require-evidence --json`. A dated input always requires a manifest. Undated inputs can run exploratory calculations without a manifest. Per-share valuation models still require explicit `unit` and `shares_unit`. Dates represent the end of the calendar day of publication. Use the accession and filing date of the actual amendment when working with restated figures.

The [META quarterly input](../examples/core_eps_input.json) and [manifest](../examples/meta-q3-2025/evidence.json) run offline. A manifest has the same issuer and fiscal period as the input. Its `facts` keys are paths to numeric fields, including array indexes. For an adjustment, include its economic `event_id` as well. Each fact carries a value, unit, evidence type and confidence grade. Use the same currency and scale throughout a financial bridge, for example `unit: "USD M"` and `shares_unit: "M"`. Monetary facts use `USD_M`, shares use `shares_M`, and prices use `USD/share`.

- For a reported fact, retain the original disclosure URL, publication date, form, accession for SEC filings, issuer, fiscal periods of the numeric columns, an exact UTF-8 text extract with headings, and its SHA-256. Snapshot paths resolve relative to the manifest. Identify the line, its leading row label and the numeric column (both one-based). Parentheses indicate negatives and a dash indicates zero. Use a factor for sign or scale conversion. For tables with different column periods in a single filing, register their extracts separately. A reported fact may specify its own two-date `fiscal_period` for historical valuation inputs.
- For an estimate or model setting, give `estimate_date` and `method`. Record the source and derivation in the method. The calculator requires reported evidence for the historical GAAP statement and EPS-note inputs. Review the accession, publication date, row meaning and column headings against the original filing when preparing extracts. The checksum pins the saved extract for subsequent runs.
- Save the JSON result with the memo. Its `evidence` object records the source metadata and bindings actually used. Linked scenario DCFs retain their own audit trail. The scenario's as-of date also limits the dates of linked models.

## Quarterly and trailing inputs

For a trailing bridge, supply `ticker`, `unit`, `valuation_shares` and `quarters` containing four ordinary bridge inputs ordered oldest first. Each quarter needs ISO `period_start` and `period_end` and its GAAP and adjustment data. Apply split restatements consistently across the four quarters. Dated workpapers use a single outer `as_of`, a manifest for the valuation share count, and one manifest per quarter. The outer period spans the four quarters. The JSON returns each full bridge plus the summed quarterly EPS, earnings to common, income, revenue and margins. Valuation shares refer to the dated equity bridge.

Set `has_nci` in a dated bridge. When true, each applied earnings adjustment and optional investment add-back needs the fraction attributable to non-controlling interests. Include the allocable percentage and its source in the workpaper. On a change from GAAP profit to Core loss, supply `gaap.basic_shares` from the EPS note or a recomputed loss denominator with `gaap.core_shares_method`. When both counts are supplied, the calculator checks they agree. Reflect associated if-converted numerator changes in the earnings bridge where applicable.
